# Vluck Auto Player V2

- Auto-start flow when the app opens.
- Automatically opens Accessibility settings if needed.
- Automatically requests screen-capture permission when Accessibility is ready.
- Detects the player from the orange face.
- Detects teal platforms and yellow danger areas.
- Searches for openings between platform runs and steers toward them.
- Victory screen: taps Continue.
- Defeat screen: taps Restart.
- STOP button remains available.

Android security still requires the user to approve Accessibility and screen-capture permissions.
